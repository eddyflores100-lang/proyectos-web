# AliceLabs · Diseños para productos digitales

Dos referencias visuales (SaaS y plataforma e-commerce) con una portada orientada a contratar adaptaciones. No hay aplicación, cuentas, cobros, checkout ni prueba gratuita operativa.

## Construir

Node 22 o superior. Ejecutar `npm ci` y `npm test`. Publicar exclusivamente `dist/` en un hosting estático que resuelva directorios con index.html. Las rutas son relativas y funcionan dentro de subdirectorios. CI adjunta el artefacto; no despliega automáticamente.

Las fuentes están en index.html, assets/ y las dos carpetas landing. No hay dependencias de aplicación. El directorio archive/legacy conserva las tres páginas originales, incluidas sus afirmaciones antiguas y terminaciones truncadas; nunca se publica.

## Qué se reparó

- La portada anterior anunciaba proyectos terminados y enlaces que no correspondían a funciones disponibles.
- Ambas demos estaban truncadas. Se conservaron sus secciones completas y se añadió un cierre con alcance real. No se recuperó contenido ausente.
- Botones ficticios desactivados sin JavaScript, enlaces internos corregidos, avisos de demo y noindex.
- Recursos externos originales de fuentes/iconos pueden no cargar sin red. Antes de una entrega, alojar recursos autorizados y sustituir marca, cifras, precios y textos ficticios.

## Venta y entrega

Solicitudes mediante borrador mailto a contact@alicelabs.site, sin envío ni captura automática. Verificar el buzón antes de publicar. Acordar páginas, contenido, revisiones, precio, fecha y hosting por escrito. Adaptar identidad y contenido reales; probar contacto y móvil; entregar código y publicación contratada. Funciones de negocio y mantenimiento se presupuestan aparte.

Los avisos de demo permanecen en este catálogo. Solo una adaptación con contenido aprobado puede presentarse como sitio real. No hay ingresos ni despliegue comprobados por este cambio.
